WHAT'S MISSING — GAPS ONLY (not what exists)
═══════════════════════════════════════════════════════════════════════════════

1. CONVERSATION RENDERING (⚠️ HIGH IMPACT)
   Missing features in ui/term_renderer.go (52 LOC):
   • No interactive diff viewer for file edits (raw text dump instead)
   • No cost/token visualization (Usage only shows cache stats)
   • No context browser for message history
   • No progress indicators for Agent/Team task execution
   • No auto-collapse/expand for large tool results
   • Minimal thinking block rendering (just dimmed text)
   • No structured output (JSON/table rendering)

   Why it matters: TypeScript has 146 UI components with Ink-based rendering.
   Go feels incomplete without visual feedback on what's happening.

2. INTERACTIVE INPUT HANDLING (⚠️ MEDIUM-HIGH IMPACT)
   Missing in repl.go (readline-based, line 186):
   • No multiline input (single-line only — users can't paste code blocks)
   • No paste detection (large clipboard pastes hang)
   • No keybinding customization (Ctrl+Enter, Ctrl+X)
   • No session-aware history persistence
   • No input token limit warnings

   Why it matters: Multiline + paste detection is BLOCKING usability.
   TypeScript users can paste 500-line files; Go users can't.

3. PERMISSION PROMPTS UI (⚠️ MEDIUM IMPACT)
   Missing in permissions/prompt.go (26 LOC):
   • No structured modal-style UI (raw stdin/stderr prompts)
   • No risk badges (can't distinguish `git status` from `rm -rf`)
   • No "Always allow" caching across operations
   • No bypass confirmation when --allow-all is active

   Why it matters: Users don't know what's dangerous. TypeScript has ⚠️ badges.

4. STREAMING DISPLAY & TOKEN COUNTING (⚠️ MEDIUM IMPACT)
   Missing in loop/query.go event types:
   • No real-time token counter display (Usage only at turn_end)
   • No streaming cost updates (cost-per-token not shown)
   • No thinking block progress indication
   • No event buffering (250ms debounce for flicker reduction)

   Why it matters: Users can't track progress during slow LLM calls.

5. GIT INTEGRATION & PROJECT DETECTION (⚠️ LOW-MEDIUM IMPACT)
   Missing in prompt/ package:
   • No project type detection (no framework/language inference)
   • No .gitignore parsing (file suggestions not filtered)
   • No branch/remote info (lower system prompt context quality)
   • No auto-file inclusion (package.json, setup.py, go.mod)

   Why it matters: System works without it, but less context-aware than TypeScript.
   Lower priority — quality-of-life improvement, not blocker.
